## 🤖 ATS OPTIMIZATION RULES

### Must Follow:

1. **Use Standard Section Headings**

   - PROFESSIONAL SUMMARY (not "About Me" or "Profile")
   - TECHNICAL SKILLS (not "Core Competencies")
   - EXPERIENCE (not "Work History" or "Employment")
   - EDUCATION (not "Academic Background")
   - PROJECTS (not "Portfolio")

2. **Avoid These Elements**

   - Tables for main content (ATS can't parse)
   - Images, icons, or graphics in content
   - Headers/footers with critical info
   - Text boxes or columns that break reading order
   - Special characters (use standard ASCII)

3. **Keyword Optimization**

   - Include exact keywords from job description
   - Use both spelled-out terms AND acronyms (e.g., "Application Programming Interface (API)")
   - Place important keywords in first 1/3 of resume
   - Include skills in both Skills section AND in experience bullet points

4. **File Format**
   - PDF is preferred for most applications
   - Ensure PDF is text-based, not image-based
   - Use standard fonts (Inter, Arial, Calibri, Times New Roman)

## 📐 FORMATTING & LAYOUT RULES

### Spacing (Tailwind Classes):

```
Section margin-bottom: mb-3 (12px)
Item margin-bottom: mb-2.5 or mb-3 (10-12px)
List item spacing: space-y-0.5 (2px)
Section title padding-bottom: pb-1 (4px)
Section title margin-bottom: mb-2.5 (10px)
```

### Typography:

```
Name: 24pt, font-weight-700, tracking-widest, uppercase
Section Titles: 11pt, font-weight-700, tracking-wide, uppercase
Body Text: 10pt, line-height 1.5
Small Text: 9.5pt for dates and secondary info
```

### Alignment:

```
Header: text-center
Experience Headers: flex justify-between items-baseline
  - Left: Company | Role
  - Right: Date (ml-4, whitespace-nowrap)
Skills: flex with fixed-width label (w-24)
Lists: ml-5, list-disc
```

### Colors (Use Tailwind custom colors):

```
Primary text: text-resume-primary (#1a1a1a)
Secondary text: text-resume-secondary (#374151)
Muted text: text-resume-muted (#6b7280)
Links: text-resume-link (#2563eb)
Borders: border-resume-primary
```

### Page Constraints (CRITICAL - MUST FOLLOW):

⚠️ **RESUME MUST ALWAYS BE EXACTLY ONE PAGE** ⚠️

- **Page Size:** 8.5" x 11" (US Letter)
- **Max Height:** 11in - content MUST NOT exceed this
- **Padding:** 0.35-0.4in top/bottom, 0.45-0.5in left/right
- **Overflow:** Set to `hidden` - content will be cut off if too long

**If content exceeds one page, you MUST:**

1. Reduce bullet points per experience (max 4 bullets)
2. Shorten bullet point text (keep under 2 lines each)
3. Remove less relevant projects
4. Condense the professional summary (3 sentences max)
5. Reduce spacing if necessary
6. NEVER let content flow to a second page

**Font Size Guidelines for One Page:**

- Name: 28pt max
- Section titles: 10pt
- Body text: 9.5pt
- Line height: 1.4-1.45

**Before any edit, verify the total content will fit on one page!**

## ✍️ CONTENT WRITING RULES

### Professional Summary:

1. 3-4 sentences maximum
2. Start with job title + years of experience
3. Include 2-3 key specializations
4. Mention 3-4 core technologies
5. End with value proposition
6. Tailor to target job keywords

### Experience Bullet Points:

1. **Start with strong action verbs:**

   - Built, Developed, Implemented, Designed, Led, Optimized, Integrated, Architected, Deployed, Created

2. **Follow CAR format (Challenge, Action, Result):**

   - ❌ "Worked on React applications"
   - ✅ "Built 5+ React applications serving 10K+ daily users, reducing load time by 40%"

3. **Include metrics when possible:**

   - Performance improvements (%, time saved)
   - Scale (users, requests, data volume)
   - Business impact (revenue, cost savings)
   - Team size or scope

4. **Maximum 4-5 bullets per role**

5. **Use present tense for current role, past tense for previous**

### Skills Section:

1. Group by category (Frontend, Backend, Databases, etc.)
2. List most relevant skills first
3. Match job description keywords exactly
4. Don't include soft skills (show them through experience bullets)
5. Maximum 6-8 categories

### Projects:

1. Include project name as heading
2. 2-3 bullet points per project
3. Emphasize technologies and outcomes
4. Include links if available (GitHub, live demo)

```html
<section class="mb-3">
  <h2 class="text-resume-section ...">SECTION TITLE</h2>

  <span class="font-semibold w-24 shrink-0 text-resume-primary">Category:</span>
  <span class="text-resume-secondary">Skill1, Skill2, Skill3</span>
</div>
```

## 🎯 TAILORING FOR JOBS

### Process:

1. **Read the job description carefully**
2. **Identify key requirements:**

   - Required skills/technologies
   - Years of experience
   - Specific responsibilities
   - Industry-specific terms

3. **Modify resume in this order:**

   - Professional Summary (include job-specific keywords)
   - Skills section (reorder to match job priorities)
   - Experience bullets (emphasize relevant achievements)
   - Projects (highlight most relevant ones)

4. **Check resources folder for:**
   - Additional experience details
   - More project examples
   - Extended skills list
   - Achievements and metrics

### Keyword Matching:

- If job says "React" → ensure "React" appears (not just "React.js")
- If job says "CI/CD" → include exactly "CI/CD"
- If job says "3+ years" → quantify experience if possible
- Mirror the exact language when possible

## ⚠️ CRITICAL REMINDERS

1. **🚨 RESUME MUST BE EXACTLY ONE PAGE - THIS IS NON-NEGOTIABLE 🚨**
2. **Before saving, verify content fits within 11 inches height**
3. **If content overflows, REDUCE content - do not let it spill to page 2**
4. **ALWAYS read job description before tailoring**
5. **NEVER use graphics or non-standard formatting**
6. **NEVER include personal info (age, photo, marital status)**
7. **ALWAYS use strong action verbs**
8. **ALWAYS include quantified results when possible**
9. **ALWAYS check that Tailwind classes are valid**
10. **ALWAYS test print output after changes**

### One-Page Checklist Before Saving:

- [ ] Total sections: 5-6 max (Summary, Skills, Experience, Education, Projects)
- [ ] Experience bullets: 3-4 per role maximum
- [ ] Project bullets: 2 per project maximum
- [ ] Summary: 3-4 sentences maximum
- [ ] Font sizes match guidelines (9.5pt body, 10pt titles)
- [ ] Margins are tight (0.35-0.45in)
