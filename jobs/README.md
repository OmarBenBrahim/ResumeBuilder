# Jobs Folder

Save job descriptions here for AI-assisted resume tailoring.

## How to Use

1. Copy the job description text
2. Create a new markdown file: `company-role.md`
3. Paste the job description
4. Ask the AI to tailor your resume for this job

## File Naming Convention

```
[company-name]-[role].md

Examples:
- google-frontend-engineer.md
- stripe-fullstack-developer.md
- anthropic-ai-engineer.md
```

## Template

```markdown
# [Company] - [Role Title]

**Company:** [Company Name]
**Role:** [Job Title]
**Location:** [Location/Remote]
**Date Found:** [Date]
**Application Deadline:** [If known]
**Link:** [Job posting URL]

## Job Description

[Paste full job description here]

## Key Requirements

- [List main requirements]
- [Technical skills needed]
- [Years of experience]

## My Relevant Experience

- [Note which of your experiences match]
- [Which projects to highlight]
- [Skills to emphasize]

## Notes

[Any additional notes for tailoring]
```
