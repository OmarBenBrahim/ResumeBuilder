# Astrolab Group - Full Stack Developer

**Company:** Astrolab Group  
**Role:** Full Stack Developer  
**Work arrangement:** On-site

## Job Description

Astrolab Group is seeking a Full Stack Developer to build robust web applications and connect intuitive interfaces to scalable backend infrastructure.

### Responsibilities

- Design and implement scalable web features using modern technologies.
- Collaborate with cross-functional teams on scope and technical requirements.
- Maintain and optimize existing codebases for performance, security, and stability.
- Participate in code reviews and uphold coding standards.

### Requirements

- Bachelor's degree in Computer Science, Engineering, or a related field.
- Experience with React or Angular plus Node.js, Python, or Java.
- Database management and RESTful API integration skills.
- Strong analytical problem solving and clean, maintainable coding practices.
